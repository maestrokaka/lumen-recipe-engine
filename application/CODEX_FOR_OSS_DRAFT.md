## Why does this repository qualify? (under 500 characters)

Lumen Recipe Engine is an offline, open-source compiler for bounded RGB animation recipes. It turns model or human-authored JSON into deterministic frames and produces pixel-level quality reports before hardware integration. It was extracted from the maintained Cyberboard Studio lighting workflow and now supports both CYBERBOARD geometry and a generic 16×16 profile. I maintain the compiler, schema, tests, and browser demo, with regression vectors from the public application.
